# CodeVerse

A modern web-based code editor and live previewer for HTML, CSS, and JavaScript. Instantly write, preview, share, and download your web code projects—all in your browser.

## Features

- ✨ Monaco-powered code editor for HTML, CSS, and JS
- ⚡ Live preview with device size simulation
- 🌗 Light/dark theme toggle
- 🔗 Shareable project links (fully client-side)
- 💾 Download your project as a ZIP
- 🧹 Reset to default template
- 📱 Responsive and mobile-friendly UI
- 🧩 Built with React, Vite, Tailwind CSS, and Radix UI

## Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm, pnpm, or yarn

### Installation

```bash
# Clone the repository
$ git clone https://github.com/MOHAMEDHAMED1S/CodeVerse.git
$ cd CodeVerse

# Install dependencies
$ npm install # or pnpm install or yarn install

# Start the development server
$ npm run dev # or pnpm dev or yarn dev
```

Visit [http://localhost:8080](http://localhost:8080) in your browser.

## Usage

- Write HTML, CSS, and JS in the Monaco editors.
- See live preview instantly, or enable manual refresh.
- Use the device size selector to test responsiveness.
- Share your project with a link or download as a ZIP.

## Project Structure

- `src/components/` – UI components and editors
- `src/pages/` – App pages (Index, NotFound)
- `src/hooks/` – Custom React hooks
- `src/lib/` – Utilities
- `public/` – Static assets
